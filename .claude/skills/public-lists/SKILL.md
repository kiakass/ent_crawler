# 공개 명단 수집 — CISO · ISMS · 산재 · 중대재해

`scripts/public_lists.py` 하나로 받기 → 파싱 → 사업자번호 찾기 → 파일 4개를 만든다. 이 스킬은 그 실행과
결과 점검 · 보고 절차다. 규칙과 함정은 CLAUDE.md '공개 명단' 문단과 `biz_crawler/public_lists.py` 상단이 기준이다.

## 인자

- 없음: 새 명단이 있을 때만 받고 파일을 만든다
- `--no-fetch`: 받지 않고 로컬 명단으로만 다시 만든다 (파서 · 규칙을 고친 뒤)
- `--refresh`: CISO · ISMS · 근로복지공단 자료를 날짜와 상관없이 다시 받는다
- `--osha-years N`: 산안법 공표 최근 N년 (기본 3)

## 절차

1. 환경

   ```bash
   cd <저장소 루트> && source .venv/bin/activate && export SSL_CERT_FILE=$PWD/certs/ca-bundle.pem
   ```

2. **외부 호출량 확인** — 근로복지공단 산재 가입 사업장 전체(약 349만 행)는 API 약 70회를 쓴다 (일 한도 9,500, 한도 장부 `kcw`).
   마지막으로 받은 지 30일이 안 지났으면 받지 않는다. `--refresh` 를 붙일 때만 사용자에게 먼저 확인한다.
   국세청 상태조회는 '후보 여러 곳' 후보만 100건씩 (처음 약 50회, 이후 캐시로 거의 0 — 한도 장부 `nts`, 일 100만).
   나머지(data.go.kr 파일 · isms-p.or.kr 128페이지 · 고용노동부 공고 PDF)는 한도가 없다.

3. 실행 — 몇 분 걸린다 (ISMS 페이지 간 1초 대기 · PDF 파싱)

   ```bash
   python scripts/public_lists.py [인자]
   ```

   받기가 실패하면 메시지를 찍고 로컬 파일로 계속한다 — 실패한 출처를 보고에 적는다.

4. 결과 점검 (터미널 출력으로)
   - 파일 4개의 `전체 · 사업자번호 있음 · 없음` 과 근거별 건수
   - `osha_YYYY: 소제목 … 사업장 A/B ✓` — 소제목 `(N개소)` 와 추출 행 수가 맞는지.
     2024 의 '’22년 사망재해 발생 사업장' 144/145 는 알려진 1건 차이다. 새 불일치가 나오면 PDF 표 구조가 바뀐 것이라 보고하고 `read_osha` 를 본다
   - 이전 실행보다 사업자번호 있음 비율이 크게 떨어지면(예: 5%p 이상) 참조 자료(`data/external/kcw/`, 공정위 `ftc_registry`)가 빠졌는지 본다

5. 보고 — **집계만**. 상호 · 사업자번호 · 주소 · 개인사업자 이름을 응답에 쓰지 않는다 (조직 지침).
   산재 명단에는 '개인사업자 ○○○' 처럼 개인 이름이 상호 자리에 오는 행이 있다 — 파일 안에만 두고 인용하지 않는다.
   형식:

   | 파일 | 행 | 사업자번호 있음 |
   |---|---|---|

   + 받은 출처 / 실패한 출처 · 쓴 API 호출 수 · 소제목 검증 결과 · 결과 위치 `output/public_lists/`

## 결과 파일 (output/public_lists/, utf-8-sig, 사업자번호는 하이픈 표기)

| 파일 | 출처 | 사업자번호 |
|---|---|---|
| `CISO_신고업체_<자료일>.csv` | data.go.kr 15080766 (중앙전파관리소) | 명단 값 · 공란만 찾음 |
| `ISMS_인증현황_<수집일>.csv` | isms-p.or.kr 인증 현황 | 상호로 찾음 · 여럿이면 CISO 신고 업체 우선 |
| `산재공표_산업안전보건법_<만든날>.csv` | 고용노동부 'YYYY년 산업재해 발생건수 등 공표' 공고 PDF | 상호 + 재해 현장 시·군·구 |
| `산재공표_중대재해처벌법_<만든날>.csv` | 고용노동부 '중대산업재해 발생사실 공표' 공고 PDF (반기) | 상호 + 발생장소 |

산안법 파일은 회사마다 한 행 — `원하청` · `원청사` · `하청사` · `공동수급사` · `사업장` · `공사·현장명` · `명단원문`.
중처법 파일은 사업자명을 '공표제목' 칸에서 가져온다 — '사업장 명칭' 칸은 현장 이름(`사업장명`). 도급인 · 수급인은 회사마다 한 행(`도급수급`), 옛 이름 `구상호`.
